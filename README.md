### Step to Practice

1. Install uv
``` 
pip install uv
```

2. Create venv
```
uv venv basicrag
```

3. Activate a venv
```
basicrag\Scripts\Activate
```

### Steps for Git and Github
1. Install git
2. Make a ID on github
3. Make Repository on github don't touch anything
4. Make a .gitignore file
5. Commands
```
git add .
```

```
git commit -m "some message"
```

```
git push
```
